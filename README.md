# frame-launcher

A [TizenBrew](https://github.com/reisxd/TizenBrew) app module for our Samsung Frame. It's a thin shell: it waits for the launcher server on the home LAN and hands the TV over to it. The real page and its server live in a private repo.

Add it in TizenBrew's module manager as `gh/Nikolai-Cook/frame-launcher`.
